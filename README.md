# Ferno Factorio Mods:
## 1- Ferno Turret:
Adds a Gun Turret with much higher attack speed and range, with infinite ammo.
## 2- Ferno Violence Watts:
*A small solution when you have too much pollution.* 
<br>(Adds a huge-buffer battery that generates electricity based on how much player-to-enemy damage is dealt around it)
